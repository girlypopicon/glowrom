# Glowrom colours and type

Shared by the Linux app, the Windows app and the website, so they all look like the same thing.

## Glowrom Pink
**`#FFA3D1`** (RGB 255, 163, 209). The tint of the subtitles: noticeably pink, still easy to read. Used with a dark plum
outline **`#1A0C14`**. Chosen by eye from rendered comparisons (plain white, a barely-there pink, this one, and a stronger
pink). It is the colour that says "you're using glowrom".

## The neon palette
Used for the on-screen messages, the title card and the idle screen. Each has a bright core and a coloured glow.

| Name        | Glow (hex) | Used for                        |
|-------------|------------|---------------------------------|
| Hot pink    | `#FF69B4`  | the default message glow        |
| Magenta     | `#FF1CE8`  | skips                           |
| Cyan        | `#1CD2FF`  | next / previous episode         |
| Green       | `#3CFF5C`  | resumed, the card's resume line |
| Amber       | `#FF9D1C`  | TV Mode                         |
| Violet      | `#9B5CFF`  | the title card                  |
| Blue        | `#4C6FFF`  | idle-screen orbs                |

The bright core of the letters is a warm white-pink, **`#FFE6F2`**.

## The idle-screen background
Deep twilight indigo **`#0B0720`**.

## Type
**Pacifico**, a cursive face by Vernon Adams (SIL Open Font License; the licence file travels with it in
`assets/fonts/`). Neon text is Pacifico with a thick coloured outline, blurred, over a white-pink core; hearts (`♥`) on either
side of messages, except the rapid ones (volume, seeking).

## In ASS (the player's subtitle format) colours are written blue-green-red
Glowrom Pink is `&HD1A3FF&` there. The neon table above is the glow in normal red-green-blue order.
